
# Sistema de Asistencia Docente
## Unidad Educativa Antofagasta

Sistema de control de asistencia mediante tarjetas RFID.

### Tecnologías
- HTML5
- CSS3
- JavaScript
- Supabase
- ESP8266
- RFID RC522
- LCD I2C

### Funcionalidades
- Administración de docentes.
- Asignación de tarjetas RFID.
- Registro de entradas y salidas.
- Control de horarios y atrasos.
- Reportes de asistencia.
- Panel administrativo.

### Publicación
GitHub Pages.

### Base de datos
Supabase PostgreSQL.
